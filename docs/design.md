# 拾钥界面规范

界面基于 shadcn/ui 与 Radix，使用统一的主题变量覆盖应用表面和弹层。本文记录当前实现约定，历次验收见 [验证记录](verification.md)。

## 视觉方向

0.2.0 采用私人账号档案册的整体方向，完整设计规范见 [设计系统](../design-system/keyfolio/MASTER.md)。

- 暖纸色背景、炭黑正文与朱红点缀，页面标题使用本地衬线字体。边框、小圆角与清晰行距贯穿所有页面和弹层。
- 页面入口移至顶部，账号页左侧成为主体目录，右侧直接显示账号列表；快速录入并入桌面页头。账号列表为默认视图，同时继续读取用户的卡片／列表、密度与排序偏好。
- 手机保留底部四页导航与中心新增按钮，快速录入压成一行，复制与平台入口直接显示在账号下方。主体选择、卡片／列表切换和批量操作继续可用。
- 主体页采用目录与内容两区，手机目录均分成三个标签；变更记录按日期分组，展开后显示字段差异；设置采用分组定位和连续表单。
- 登录改为档案册介绍与表单并列；账号详情使用桌面右侧面板和手机全屏；聊天继续以对话空间为主，桌面显示草稿侧栏，手机按需展开。
- 深色主题、125% 字号、键盘焦点、减少动态效果和设备安全区域同步适配。页面不请求外部字体或装饰图片。

## 控件约定

业务页面通过 `src/components/ui` 的组件交互，不直接编写原生按钮、下拉列表、文本框、文本域、展开面板或浏览器确认对话框。

- 按钮与导航：Button，导航链接使用 `asChild`。
- 输入与选择：Input、Textarea、Checkbox、Select。
- 弹层：Dialog、AlertDialog、DropdownMenu。
- 退出登录、退出体验以及放弃未保存内容使用统一 AlertDialog；默认聚焦保留内容的操作，Esc 只取消最上层确认框。有修改才提示放弃，成功保存和自动锁定直接完成原流程。
- 分段切换：具备 `aria-pressed` 状态的 Button。
- 展开内容：Collapsible。
- 文件上传：自定义文件卡片及 Button 触发隐藏 Input；系统文件选择器由浏览器打开。

`src/vault/components/controls.tsx` 包含统一的 FieldSelect、FieldOption、Disclosure 和 BackupPicker。Select 值使用固定前缀编码，兼容未分配主体的空字符串与设置中的数字值；提交给业务逻辑时恢复原值。

## 检查范围

执行格式、静态分析、类型检查、业务测试和生产构建；通过 Chromium 自动化验证桌面和手机视口的实际点击、键盘操作与截图。已检查 375px 窄屏、横屏、深浅主题、125% 字号和减弱动画设置。业务页面不使用上述原生控件与浏览器 alert／confirm／prompt。尚未进行 iOS Safari、Android 真机或真实软键盘验收，不能将模拟视口结果视为真机保证。
