## 复现命令

```bash
pnpm install --frozen-lockfile
pnpm check
pnpm exec playwright install chromium
pnpm test:browser
```

`pnpm check` 包括格式、ESLint、Node 测试、前端与测试类型检查、生产打包及后端编译。浏览器回归使用独立端口和临时账号库，结果位于 `work/browser-results/`。

需要检查镜像时单独执行：

```bash
docker build -t keyfolio:local .
pnpm test:docker
```

容器演练创建临时容器和命名卷，验证保存、重启、备份还原后清理自身资源。依赖公告需按执行时间重新查询：`pnpm audit`。
