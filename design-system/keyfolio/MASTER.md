# 拾钥：私人账号档案册

这份规范对应 0.2.0 的全站界面重构。设计检索使用 ui-ux-pro-max，最终按账号管理产品的实际信息与操作取舍；营销页大横幅、装饰统计图和持续动画不适用于本项目。

## 风格与文字

暖纸色背景、炭黑正文、朱红交互色，使用平直分隔线与 8px 为主的小圆角。中文页面标题使用设备本地宋体／衬线字体，表单和账号内容使用系统无衬线字体，数字与密钥使用本地等宽字体。没有外部字体请求。

| 用途     | 浅色      | 深色      |
| -------- | --------- | --------- |
| 页面背景 | `#f5f2ec` | `#1e1c19` |
| 内容表面 | `#fffefa` | `#27241f` |
| 正文     | `#2d2a26` | `#efeae1` |
| 次要文字 | `#716b62` | `#b9afa2` |
| 主操作   | `#af4635` | `#f0ab94` |
| 分隔边框 | `#ded9d0` | `#474036` |

标题 28–34px，主要账号名称 15px，次要信息 13px，辅助文字 11–12px。小尺寸只用于非主要的说明与数字；手机输入为 16px，允许系统字号放大。表面依赖色差与边线区分，避免多层阴影叠加。

## 页面结构

- 桌面：统一顶部导航，当前页面有明确选中状态。页头包含标题、快速录入、导入与新增；账号页左侧只承载主体目录及账号检查，右侧直接呈现搜索和账号集合。
- 账号：默认列表，保留用户已保存的卡片／列表、密度和排序偏好。复制账号、复制密码、打开平台、编辑与删除无需绕行。主体筛选切换会清除旧批量选择。
- 手机：底部四个页面入口与中心新增按钮。快速录入占一行，主体选择位于搜索区；卡片／列表切换保留，账号检查位于工具菜单和列表下方。底栏下方包含设备安全区域。
- 主体与分类：桌面使用左侧目录、右侧内容；手机目录转为同一行三个可点击标签，宽度均分，禁止将页面撑大。
- 变更记录：按本地日期分组，日期在桌面左列、手机上方；每条记录可展开字段差异并恢复。
- 设置：桌面左侧分组定位，手机为两列跳转入口。各设置表单保留在页面中，支持直接定位与键盘操作。
- 详情：桌面靠右的大面板，手机占完整视口。凭据优先显示，其余信息按两列归档；编辑和删除保留在面板底部。
- 聊天：尽量占满可用视口，桌面草稿在侧边、手机可折叠；对话空间优先，输入、停止、重试与保存流程保持可达。
- 登录：档案册介绍与表单分列，手机保留短标题和表单。创建、解锁、恢复、双重验证、备份恢复使用同一套控件。

## 控件与验收

统一使用 shadcn/ui 和 Radix。页面路由使用 Link，表单交互使用 Button、Input、Select、Checkbox，编辑与确认分别使用 Dialog、AlertDialog。焦点可见，退出与放弃草稿仍按原规则确认。密码默认隐藏，锁定清空明文状态。

每次调整检验 375px 手机、横屏、900px 平板及 1280／1440px 桌面，覆盖深色与 125% 字号。尤其检查短页面切换、固定底栏、标签宽度、弹层层级和第一条账号的完整可见性。所有动态效果遵循系统减少动态设置。

共享主题和业务控件位于 `src/styles/vault.css`，账号及整理控件位于 `src/styles/collection.css`，应用布局与本次档案册视觉位于 `src/styles/workspace.css`。删除已退出源码的旧侧栏、概览卡和登录装饰选择器，避免继续累积无效规则。
